# Changelog

## 1.0.0 (2026-11-19)

The first release.

- Import recipes from a link (most cooking sites), paste them from anywhere, or write your own.
- Cook mode: one step at a time in large type with the screen kept on, the ingredients each step uses, and
  keyboard and remote control.
- Timers that start from the step itself, several at once, ringing out loud and notifying when the window is away.
- Scaling by servings with amounts written the way cooks write them.
- Shopping list sorted by aisle; favorites, tags, search by ingredient and "Surprise me".
- Community: browse and save recipes other Simmer cooks shared and share your own; text only, checked
  automatically, reportable.
- Backups to a file.
- Simmer Plus (optional, through Stripe): meal planner, smart shopping list for the week, metric and US units, and
  the cooking log.
- Update alerts from GitHub releases; Depot copies update through Depot.
