# Security

Simmer reads recipe pages from anywhere on the internet and shows recipes other people shared. If a page, a shared
recipe or a backup file can crash the app, hang it, or do something it shouldn't, or if you find a way past the
community's safety checks, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/chartmann1590/simmer/security/advisories/new)
rather than a public issue.
